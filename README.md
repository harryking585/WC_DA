Data Analysis Project based around data pulled from the popular game World of Warcraft.
**This project has evolved into a fullstack application with the introduction of react and node.


The goal of this project is to create a dynamic dashboard of a character's Mythic+ progress and give insights
into their overall performance, tendencies, trends, etc. 



For those unfamiliar Mythic+ is an environment where 5 players enter an instance and aim to complete the instance within
the pre-determined timer. The difficulty of the instance grows exponentially as players tackle higher instances.

For example: The difficulty difference between a Mythic+2 and a Mythic+3 is small compared to the difference between a Mythic+4 and a Mythic+5.

Enhancement => Cross-Seasonal Progression. Stack your performance from a season by season basis up against each other to see how much you've improved.
